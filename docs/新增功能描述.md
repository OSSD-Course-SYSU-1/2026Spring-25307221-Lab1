# 新增功能描述：聊天消息搜索

## 一、功能概述
在聊天页面增加实时搜索功能，用户可输入关键词快速过滤当前聊天记录，并高亮显示匹配内容。

## 二、修改文件
| 文件 | 修改说明 |
|------|----------|
| entry/src/main/ets/pages/ChatPage.ets | 添加搜索状态、搜索图标、搜索框UI、列表过滤逻辑、高亮样式 |

## 三、核心实现
1. 使用 @State showSearch 控制搜索框显隐，@State searchKeyword 绑定输入内容。
2. 在 ForEach 渲染消息列表时，应用 Array.filter() 根据 searchKeyword 过滤。
3. 通过动态绑定 fontColor 实现匹配消息高亮（红色文字）。
